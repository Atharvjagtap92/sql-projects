# 🗄️ SQL Projects Collection

This repository contains a collection of my SQL-based projects, each demonstrating different aspects of database design, normalization, and query optimization. These projects were developed using MySQL and focus on real-world scenarios involving schema creation, data manipulation, and analytical queries.

---

## 📂 Projects Overview

### 1. 🎬 Actors and Films Database
- Designed and implemented a relational schema for managing movie data, actors, and film categories.
- Applied **JOINs**, **GROUP BY**, and **aggregate functions** for analytical insights.

### 2. 🧑‍💼 HR Schema
- Simulated an HR database with employee, department, and job-related data.
- Created and executed **DDL/DML commands**, **constraints**, and **subqueries** for employee analytics.

### 3. 🏪 Retail Store (SQL)
- Built a retail store database to track sales, products, and inventory.
- Performed **data extraction and reporting** using complex SQL joins and nested queries.

### 4. 💻 SQL Scripts
- A collection of standalone SQL scripts for practice.
- Includes **table creation**, **stored procedures**, **views**, and **user privilege management**.

### 5. 🎵 sTunes Database
- Modeled a music store database inspired by iTunes.
- Focused on **data normalization**, **foreign key relations**, and **query optimization**.

---

## 🧠 Key Skills Applied
- Database Design (ER Models, Normalization)
- SQL Query Writing (DDL, DML, DCL, TCL)
- Aggregate Functions, Joins, and Subqueries
- Data Integrity and Relationship Management
- MySQL Workbench and Command Line Interface
